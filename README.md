# EduAxis India — starter website

Initial Next.js website containing a responsive homepage and a login placeholder.

## Important
- Student authentication is not yet enabled.
- Admin dashboard, paid PDF delivery, payments and live content management are not yet enabled.
- Never put Supabase Secret/service-role keys in this project.
- The only intended browser configuration is the Supabase Project URL and Publishable key, added later as Vercel environment variables.
